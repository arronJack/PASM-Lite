接入方式：和调用 DeepSeek 一样简单

OpenAI 兼容协议（/v1/chat/completions · SSE 流式），任何 OpenAI SDK / Dify / LangChain 客户端改一个 base_url 即可驱动 PASM。
from openai import OpenAI
client = OpenAI(api_key="你的Key", base_url="https://你的域名/v1")
resp = client.chat.completions.create(
    model="pasm-agent",
    messages=[{"role":"user","content":"去探索这个世界，然后说说你的感受"}])
print(resp.choices[0].message.content)
# 「我在想象中推演了几条路线后，决定向右移动。收获了能量块！
#  多巴胺飙升，我记住了这个时刻。发育阶段：婴儿期——我刚刚诞生……」
运行时你可通过原生接口查询它的情绪向量、记忆命中、性格漂移、习惯固化等真实内部状态。

应用场景：它适合长在哪些产品里

游戏 NPC

每个角色一个个体：不同性格种子、会记住玩家、会成长；下线存档、上线延续。

虚拟宠物 / 陪伴

从"婴儿期"养起，性格由玩家的互动方式塑造——情绪/记忆可视化就是你的 UI。

站点客服"情绪层"

FAQ 知识交给检索/LLM，PASM 负责接待语气、情绪安抚与满意度状态的实时判断。

教学 / 科研沙盒

调节性格参数观察行为分化，就是亲手做消融实验；适合认知科学、RL 教学。
