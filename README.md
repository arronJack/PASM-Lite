# PASM-Lite — 零 token 认知循环 · 教学最小实现

> AI 的"思考"一定要生成 token 吗？
> PASM-Lite 用 ~260 行代码演示另一种答案：
> **感知 → 工作记忆 → 情景记忆检索 → 世界模型"想象" → 规划 → 行动**，
> 全程连续潜在向量，没有任何 token 生成。

## 它演示了什么

- **层 0 感知**：观测(27 维) 被自编码器压缩成 8 维潜在向量 `z`
- **层 1 工作记忆**：最近 4 步的上下文 `c`
- **层 2 情景记忆**：KNN 检索相似经历 + "只在惊讶/奖励异常时写入"（事件驱动）
- **层 3 世界模型**：GRU 在潜在空间预测 下一状态 `z′` 与奖励 `r`
- **规划**：采样 16 条动作序列在世界模型里"想象"，挑累计奖励最高的一条

运行输出示例：

```
世界模型预热 …
episode 0: reward -14.60 | 能量 1 | 情景记忆 1 条
episode 20: reward -12.40 | 能量 1 | 情景记忆 14 条

平均奖励(末5集): -15.50（前5集 -15.74）
```

## 快速开始

```bash
pip install torch            # CPU 即可
python pasm_lite.py
```

改一改就玩：`GridWorld(n_food=12)` 让食物更密；`Episodic(k=5)` 调检索宽度；
`Planner(n_seq=32)` 增加"想象"预算——观察行为与记忆增长的变化。

## 诚实边界（重要）

PASM-Lite 是**教学骨架**，不是性能基线：
- 训练预算很小，任务是"学会活着并找吃的"，演示重点是**机制与记忆可见**，
  不是刷分；
- 强行为表现依赖奖励信号工程、探索策略、记忆阈值调优等细节；
- 一个很好的练习：把它逐步"喂"成完整引擎（对照下表），每加一块看效果变化。
